## How to contribute to Ilch

#### **Did you find a bug?**

* **Do not report security vulnerabilities in public issues.** Contact the Ilch team privately instead: [Ilch Team](https://www.ilch.de/team.html).
* **Ensure the bug was not already reported** by searching on GitHub under [Issues](https://github.com/IlchCMS/Ilch-2.0/issues).
* Please test against the latest ilch release or current development state before opening a bug report.
* If the bug involves a module or layout, please also use the latest version of that module/layout.
* If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/IlchCMS/Ilch-2.0/issues/new/choose). Include a clear title, description, and relevant version information.
* Use the relevant issue template.

#### **Did you write a patch that fixes a bug?**

* Open a pull request with your changes.
* Use the repository pull request template.
* Clearly describe the problem and solution, and include the relevant issue number if applicable.

#### **Do you intend to add a new feature or change an existing one?**

* Open a pull request with your changes.
* Use the repository pull request template.
* Keep in mind that the Ilch CMS isn't only intended for usage in gaming clans, but also for a more general usage. Features therefore should be useful outside the gaming world too.

#### **Before opening a pull request**

* Keep changes focused.
* Follow the existing code style.
* Run the relevant tests if available.
* Update documentation if the behavior changes.
* By contributing code, you agree that your contribution is licensed under GPL-3.0.

#### **AI-assisted contributions**

AI assistance is allowed, but it must be disclosed in the pull request using the repository pull request template.

If AI assistance was used:

* Mark the AI assistance checkbox in the PR template.
* Briefly describe what was generated and how it was verified.
* Ensure the contribution is compatible with this project's GPL-3.0 license and does not contain copied third-party copyrighted text.

The contributor submitting the PR is fully responsible for reviewing and validating the content.

#### **Do you have questions about Ilch?**

* Ask any question about it in the [official forum](https://www.ilch.de/forum.html).

Thanks!
