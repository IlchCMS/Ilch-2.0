### Ilch 2 [![CI](https://github.com/IlchCMS/Ilch-2.0/actions/workflows/ci.yaml/badge.svg)](https://github.com/IlchCMS/Ilch-2.0/actions/workflows/ci.yaml)

Ilch 2 is the direct successor to Ilch 1.1.

### Latest Release (for users)

- [Download the latest release](https://github.com/IlchCMS/Ilch-2.0/releases/latest)

### Current Development Status (for developers and testers)

- User version: [Download](http://www.ilch.de/ilch2/versions/master.zip)
- Developer version: [Download](https://github.com/IlchCMS/Ilch-2.0/archive/master.zip)
- Developer version with Vagrant: Clone the repository and follow the instructions in the [development README](https://github.com/IlchCMS/Ilch-2.0/blob/master/development/README.md).

### Installation

1. Place the files in your web directory.
2. Open `/index.php` in your browser.
3. Follow the on-screen instructions.

### Installing the Developer Version

1. Place the files in your web directory.
2. [Install Composer](https://getcomposer.org/download/) if it is not already installed. Alternatively, run `development/bin/setup.sh`.
3. Run `composer install` to install the required dependencies.
4. Open `/index.php` in your browser.
5. Follow the on-screen instructions.

### Requirements

- PHP 8.1 or newer
- MySQL 5.5.3 or newer, MariaDB 5.5 or newer, or an equivalent database system
